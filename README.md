
# Distributed P2P Network

Implementation of a peer-to-peer distributed system in C, based on a ring network architecture.

## Features
- Peer initialization and network integration.
- Ring topology and successor management.
- Client-server communication using TCP sockets.
- Remote node information and lookup operations.
- File search and download operations.
- Parallel download functionality.
- Concurrent request handling using threads.

## Technologies
- C
- TCP/IP
- BSD Sockets
- POSIX Threads
- Distributed Systems
- Network Programming
- File I/O

## Project Structure
- `main.c`: Main application.
- `ring_srv.c`: Server-side operations.
- `ring_cln.c`: Client-side operations.
- `common.c`: Shared functionality.
- `include/`: Header files.
